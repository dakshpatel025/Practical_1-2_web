Administration Overview

This page is an informational template. Administrative actions require a separately authenticated staff account and are not available from this public page.

Students

Student accounts and password hashes are stored in the students table. Email addresses are unique.

Events

Event details and seat capacity are managed in the events table.

Registrations

Registrations link students to events with foreign keys. A unique constraint prevents duplicate event bookings.

Set up the database using database/schema.sql and follow the configuration guide in database/README.md.
